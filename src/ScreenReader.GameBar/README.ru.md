# LazySkald — Xbox Game Bar

Это отдельный виджет UWP для Xbox Game Bar. Основное приложение продолжает
распознавать текст, переводить и озвучивать его. Виджет показывает текущий этап,
перевод, время и прогресс; кнопки управляют паузой и закрытием текущей задачи.

## Сборка и установка

Для сборки нужны Visual Studio 2022 с инструментами UWP (.NET Native),
Windows SDK 10.0.22621.0 и доступ к NuGet. Основное приложение собирается
обычной командой `./build.ps1`, виджет — отдельно:

```powershell
./build-gamebar.ps1
```

Результат: `artifacts/LazySkald-GameBar`. По умолчанию MSIX не подписан.
Для локальной установки включите **Режим разработчика** в настройках Windows
и выполните из каталога результата:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./Install-GameBar.ps1 -Development
```

Скрипт регистрирует виджет для текущего пользователя, устанавливает отсутствующие
зависимости UWP из каталога сборки и не меняет системные настройки разработчика.
Каталог `Development` нельзя перемещать после регистрации. Для удаления:

```powershell
Get-AppxPackage -Name LazySkald.GameBar | Remove-AppxPackage
```

Для распространения без режима разработчика нужен сертификат подписи кода
с Subject `CN=LazySkald`, которому доверяют целевые компьютеры:

```powershell
./build-gamebar.ps1 -CertificateThumbprint '<отпечаток сертификата>'
```

Подписанный MSIX и зависимости находятся в подкаталоге `*_Test`.
Сертификаты, доверие и публикация в Microsoft Store не настраиваются сборкой.

## Использование

1. Установите Xbox Game Bar и виджет.
2. В LazySkald откройте **Overlay**, включите оверлей и выберите
   **Способ отображения → Xbox Game Bar**. Сохраните настройки.
3. Нажмите **Win+G → меню виджетов → LazySkald**. Закрепите виджет булавкой,
   чтобы он оставался видимым после закрытия Game Bar.
4. Перемещайте и меняйте размер средствами Game Bar. Для кнопок и прокрутки
   используйте Win+G; клавиша Alt относится к обычному оконному оверлею.

Если виджет закрыт, не установлен или перестал отвечать, в течение трёх секунд
возвращается обычный оверлей. Пауза и ожидающий закрытия перевод сохраняются,
поэтому можно продолжить работу через его кнопки. При подключении виджета
обычный оверлей скрывается. Положение и размер в Game Bar сохраняет сама Game Bar.
Совместимость с конкретной игрой и её полноэкранным режимом нужно проверить на месте.

## Связь процессов

Протокол версии 1 использует локальные JSON-файлы в
`%LOCALAPPDATA%/Packages/<семейство LazySkald.GameBar>/LocalState/Overlay`.
Основное приложение находит установленный пакет через Windows PackageManager.
В состоянии доступны только показанный перевод и состояние текущей задачи;
распознанный оригинал, снимок экрана, настройки и ключи API не передаются.
Состояние обновляется атомарно, очищается при выключении режима и штатном выходе.
При аварийном завершении файл перевода может остаться до следующего запуска;
виджет скрывает устаревший текст через три секунды. Это локальные файлы пользователя,
а не сетевой сервис. Команды привязаны к случайному идентификатору запуска и ID
текущей задачи, потребляются один раз; устаревшие команды отбрасываются.

Основа интеграции: [официальные примеры Microsoft](https://github.com/microsoft/XboxGameBarSamples),
[манифест виджета](https://learn.microsoft.com/en-us/xbox/game-bar/guide/pkg-manifest).
SDK: Microsoft.Gaming.XboxGameBar 7.3.2607010; условия — `GameBar-SDK.txt`.
